System Information

ResumeAI · About

🧠
ML Scoring Engine

XGBoost regression pipeline trained on thousands of resumes. Scores 0–100 based on skills, experience, education tier, certifications, and project count. Features: Edu_Tier, Has_Cert, Skill_Exp_Score interaction terms.

⚡
Groq LLM Backend

Llama-3.3-70b-versatile via Groq API powers all generative features. Interview questions, cover letters, LinkedIn summaries, salary estimates, rewrite suggestions, and 90-day roadmaps.

🔒
Zero Data Retention

Your resume is processed in memory and immediately discarded. Nothing is stored, logged, or transmitted beyond the scoring session. Complete privacy by design.

📄
Supported Formats

PDF (pdfplumber), DOCX (python-docx), and plain TXT. Batch mode supports up to 20 simultaneous files with full ranking and CSV export.
